## 二、产品核心信息
### 2.1 产品名称
- 中文：
- 英文：SnapKeep

### 2.2 核心 Slogan
一瞬收藏，数据自持；轻量无扰，随取即用。

### 2.3 产品模式
v0.1.0-alpha.1 采用**本地优先 + 可选备份代理**模式，所有数据默认存储于用户浏览器本地，无用户系统；用户可通过备份代理服务接入 WebDAV 或使用本地文件导出/导入完成备份与恢复。

### 2.4 核心亮点
1. 无需注册、无需登录，打开即用
2. 无数据上传、无信息收集、隐私安全
3. 极简操作，三步完成灵感捕获
4. 支持标签管理与全局模糊搜索
5. 支持 WebDAV 备份与本地 JSON 导出/导入双通道（WebDAV 通过备份代理增强兼容性）
6. 前端纯静态页面，可选部署备份代理服务
7. 响应式设计，适配 PC、手机、平板
8. 亮色/暗色双模式，跟随系统或手动切换

## 三、市场与用户分析
### 3.1 行业核心痛点
1. 主流便签、笔记工具**强制云同步、强制账号登录**，用户数据存在泄露风险
2. 专业笔记产品**功能冗余，操作繁琐**，不适合碎片化信息临时捕获
3. 设备自带便签**跨端使用困难**，不支持用户自主掌控数据
4. 程序员、隐私敏感用户缺乏**轻量、本地、可私有化部署**的碎片存储工具

### 3.2 目标用户画像

**Persona A：程序员/开发者**
| 维度     | 描述                                               |
| -------- | -------------------------------------------------- |
| 典型场景 | 调试时快速保存报错信息、代码片段、技术文章摘录     |
| 使用频次 | 日活，每次 1-3 分钟                                |
| 设备偏好 | PC 优先，偶尔移动端查阅                            |
| 核心痛点 | 需要快速粘贴保存，不想打开重型笔记软件             |
| 内容类型 | 代码片段（40%）、技术笔记（30%）、链接/灵感（30%） |

**Persona B：隐私敏感型用户**
| 维度     | 描述                                              |

| 典型场景 | 保存私密笔记、个人想法，拒绝任何云端存储          |

| 设备偏好 | PC 为主                                           |

| 内容类型 | 个人笔记（60%）、敏感信息（20%）、日常记录（20%） |

**Persona C：极简工具爱好者**

| -------- | ---------------------------------------------- |

| 内容类型 | 纯文本（70%）、短句/灵感（30%）                |

**Persona D：极客/自部署用户**
| 维度     | 描述                                     |

| 使用频次 | 部署一次后日常使用                       |
| 设备偏好 | PC 部署，多端使用                        |
| 核心痛点 | 希望完全掌控工具与数据，不依赖第三方服务 |
| 内容类型 | 混合型，与 Persona A 重叠度高            |

## 四、核心使用场景
### 4.1 【P0】快速捕获灵感碎片
用户浏览内容时看到优质句子、代码、链接、观点，无需打开复杂软件，打开 SnapKeep 即可粘贴保存，添加标签快速归类。

### 4.2 【P0】碎片化内容临时暂存
复制的文本、工作要点、临时信息无需担心丢失，本地持久化存储，随时查看与复用。

### 4.3 【P1】历史内容快速检索
通过关键词或标签，从大量历史记录中实时检索，快速定位目标内容。

### 4.4 【P1】数据备份与多端手动同步
用户在 PC 端保存内容后，通过备份代理接入 WebDAV 备份至个人云盘或导出 JSON 文件，手机端恢复/导入数据，实现跨端手动同步。

### 4.5 【P2】私有化部署自主使用
用户将产品部署至个人服务器、GitHub Pages、Vercel 等平台，完全脱离官方环境独立使用。

### 4.6 边界场景与应对

| 场景             | 描述                                         | 产品应对                                                   |
| ---------------- | -------------------------------------------- | ---------------------------------------------------------- |
| 大量记录         | 用户累积 1000+ 条记录，浏览和搜索效率下降    | 列表分页加载（每页 50 条），搜索结果实时过滤               |
| 换设备/换浏览器  | 用户更换设备但忘记备份，本地数据丢失         | 首次使用时提示备份重要性；记录数 > 10 条时定期弹出备份提醒 |
| 浏览器数据被清理 | 系统清理工具或手动清除浏览器数据导致记录丢失 | 同上备份提醒机制；设置面板展示上次备份时间                 |
| 存储空间不足     | 浏览器 IndexedDB 存储接近配额上限            | 展示已用存储量，接近阈值时提醒用户导出或清理旧记录         |

## 六、功能详细描述

### 6.1 记录录入功能（FR-001）
1. 页面加载完成后，输入框自动聚焦，支持直接输入或粘贴内容
2. 系统自动提取内容前 20 字作为记录标题
3. 支持标签录入，以空格或逗号分隔多个标签
4. 按下 `Ctrl+Enter`（Windows/Linux）或 `Cmd+Enter`（macOS）快速保存；回车键保持换行功能
5. 保存成功后，输入框自动清空，保持聚焦状态，支持连续录入
6. 内容为空时点击保存，显示提示"请输入内容"

**验收标准**：
- AC-001: 页面加载后输入框自动获得焦点
- AC-002: 输入超过 20 字的内容保存后，记录标题为前 20 字
- AC-003: 输入"标签A 标签B,标签C"后保存，记录包含 3 个独立标签
- AC-004: Ctrl/Cmd+Enter 触发保存，回车键在输入框中换行
- AC-005: 保存成功后输入框清空且保持聚焦

### 6.2 记录列表功能（FR-002, FR-003）
1. 以卡片形式展示所有记录，按创建时间倒序排列
2. 每张卡片展示标题、标签、创建时间、操作按钮
3. 操作按钮包含：一键复制、编辑、删除
4. 无记录时展示空状态提示文案
5. 删除操作前触发二次确认弹窗，防止误删
6. 列表采用分页加载，每页展示 50 条，滚动触底自动加载下一页

**验收标准**：
- AC-006: 新记录始终出现在列表顶部
- AC-007: 点击删除后弹出确认弹窗，确认后记录消失，取消后无变化
- AC-008: 一键复制后剪贴板内容与记录内容一致
- AC-009: 空状态下展示引导提示文案
- AC-010: 记录超过 50 条时滚动触底加载更多

### 6.3 全局搜索功能（FR-004）
1. 顶部固定搜索框，输入内容实时检索
2. 检索范围覆盖记录内容与标签
3. 支持中英文、数字、符号全模糊匹配，不区分大小写
4. 搜索结果实时刷新，清空关键词恢复完整列表
5. 搜索状态下展示匹配条数

**验收标准**：
- AC-011: 输入关键词后 200ms 内展示匹配结果
- AC-012: 搜索"test"能匹配内容含"Test"或"TEST"的记录
- AC-013: 搜索关键词能匹配标签内容
- AC-014: 清空搜索框后恢复完整列表
- AC-015: 无匹配结果时展示"未找到相关记录"提示

### 6.4 标签管理功能（FR-005）
1. 录入时支持多标签快速输入，自动格式化展示
2. 标签以小色块样式展示，视觉清晰
3. 搜索功能可直接匹配标签内容
4. 编辑记录时可同步修改标签

**验收标准**：
- AC-016: 标签以独立色块形式渲染，视觉可区分
- AC-017: 编辑记录时修改标签后保存，列表中标签同步更新

### 6.5 WebDAV 备份与恢复（FR-006）
1. 支持配置 WebDAV 服务器地址、用户名、密码（长期保存）
2. 密码输入框支持显示/隐藏切换
3. 提供连接测试功能，返回成功/失败明确提示
4. 一键备份：将本地所有数据加密后上传至个人云盘
5. 一键恢复：展示云端备份文件列表（按时间倒序），用户选择目标文件后下载解密并覆盖本地存储
6. 备份文件默认加密，加密密码由用户设置
7. 恢复操作前触发二次确认提示："恢复将覆盖本地数据，是否继续？"
8. 备份/恢复过程中展示进度状态（加载中/成功/失败），禁止重复点击
9. 若备份/恢复因网络异常中断，显示明确错误提示并允许重试

**验收标准**：
- AC-018: 填写完整配置后连接测试返回成功/失败结果
- AC-019: 配置不完整时测试按钮不可用或给出提示
- AC-020: 备份成功后云端生成加密备份文件
- AC-021: 恢复时展示备份文件列表，选择后二次确认，确认后本地数据被覆盖
- AC-022: 备份/恢复过程中按钮显示加载状态，不可重复点击
- AC-023: 网络异常时显示错误提示并提供重试入口

### 6.6 本地导出/导入功能（FR-007）
1. 一键导出：将本地所有记录导出为 JSON 文件，自动下载至用户设备，文件名格式：`snapkeep-export-YYYYMMDD.json`
2. 一键导入：用户选择本地 JSON 文件，解析后导入记录
3. 导入前触发二次确认："导入将覆盖本地数据，是否继续？"
4. 导入文件格式校验失败时，显示明确错误提示
5. 导出/导入操作均在设置面板中操作

**验收标准**：
- AC-024: 点击导出后浏览器下载 JSON 文件，文件内容包含所有本地记录
- AC-025: 导入有效 JSON 文件后本地数据被覆盖，列表刷新
- AC-026: 导入非法文件（非 JSON / 格式不符）时显示错误提示，本地数据不受影响
- AC-027: 导入前弹出二次确认弹窗

### 6.7 亮色/暗色模式切换（FR-008）
1. 支持三种模式：跟随系统（默认）、手动亮色、手动暗色
2. 切换入口位于顶部区域（图标按钮）
3. 用户手动切换的偏好持久化存储于本地
4. 暗色模式下所有页面元素（卡片、弹窗、输入框、设置面板）统一适配

**验收标准**：
- AC-028: 默认跟随系统主题，系统切换暗色后页面自动切换
- AC-029: 手动切换后刷新页面，模式偏好保持不变
- AC-030: 暗色模式下所有文字可读，对比度符合 WCAG AA 标准

### 6.8 设置面板功能
1. 采用右侧抽屉式设计，可展开/收起
2. 包含 WebDAV 配置区、备份恢复操作区、本地导出/导入区、数据统计区
3. 展示产品版本号、上次备份时间、隐私说明、部署说明入口
4. 支持点击关闭按钮或点击遮罩区域收起
5. 移动端下抽屉宽度占满屏幕

**验收标准**：
- AC-031: 点击设置按钮后抽屉从右侧滑出
- AC-032: 点击遮罩或关闭按钮后抽屉收起
- AC-033: 移动端抽屉宽度为 100%

### 6.9 编辑功能（FR-002）
1. 支持对已有记录的内容与标签进行修改
2. PC 端以弹窗形式展示，弹窗宽度 600px；移动端以全屏形式展示
3. 支持确认保存或取消修改
4. 编辑时内容输入框自动聚焦

**验收标准**：
- AC-034: 点击编辑后弹窗展示当前记录内容和标签
- AC-035: 修改内容后点击确认，列表中对应卡片更新
- AC-036: 点击取消后内容不变
- AC-037: PC 端弹窗宽度 600px，移动端全屏展示

### 6.10 三态交互规范
所有涉及异步操作（备份、恢复、导入、导出、连接测试）的功能，统一遵循以下三态规范：

| 状态    | 表现                                                   |
| ------- | ------------------------------------------------------ |
| Loading | 操作按钮显示加载动画，禁止重复点击；展示操作中提示文案 |
| Success | 显示成功提示（自动消失，持续 2 秒）                    |
| Error   | 显示错误原因，提供重试入口                             |

## 八、业务规则
1. 所有数据默认仅存储于用户本地浏览器；仅在用户主动备份/恢复时经备份代理转发至个人 WebDAV
2. 无用户系统、无登录逻辑，数据与设备浏览器绑定
3. 清除浏览器数据会导致本地记录丢失，需通过备份/导出恢复
4. 备份、恢复、导出、导入仅在用户主动操作时触发
5. 单条记录支持永久存储，直至用户手动删除
6. 记录按最新创建时间优先展示，不支持手动排序
7. 搜索不区分大小写，实时匹配无需确认
8. 产品不提供官方云端同步与分享能力
9. 本地导出文件为明文 JSON；WebDAV 备份文件为用户密码加密的 JSON
10. 亮暗模式偏好持久化存储于本地浏览器，默认跟随系统
11. 单条记录内容上限 100KB；本地总存储接近 50MB 时触发提醒

## 九、非功能需求
### 9.1 性能需求
1. 页面首次加载完成时间 ≤ 1 秒（静态资源 gzip 后）
2. 保存、删除、复制操作响应时间 ≤ 200ms
3. 搜索输入后结果刷新时间 ≤ 200ms
4. 支持本地存储 1000 条以上记录，列表滚动帧率 ≥ 30fps

### 9.2 安全需求
1. 不上传、不收集、不泄露用户任何数据
2. WebDAV 配置信息加密存储（备份代理服务端）
3. WebDAV 备份文件采用用户设置的密码加密，产品方无法解密
4. 本地导出文件为明文，由用户自行保管

### 9.3 兼容性需求
1. 最低浏览器版本：Chrome ≥ 80、Edge ≥ 80、Firefox ≥ 78、Safari ≥ 14
2. 适配目标分辨率：375px（手机）、768px（平板竖屏）、1024px（平板横屏/小屏 PC）、1440px（PC）
3. 支持所有静态网站平台私有化部署（GitHub Pages、Vercel、Nginx 等）

### 9.4 体验需求
1. 核心操作路径（录入→保存）不超过 3 步
2. 无引导页、无广告、无弹窗打扰
3. 面向用户的文案简洁通俗，无专业技术术语
4. 错误操作提供清晰易懂的提示，包含具体原因
5. 暗色模式文字对比度符合 WCAG AA 标准（≥ 4.5:1）

## 十三、隐私说明
1. SnapKeep  v0.1.0-alpha.1 为本地优先工具，所有数据默认仅存储于用户设备浏览器中
2. 产品不会上传、收集、共享任何用户内容与行为数据
3. WebDAV 备份仅用户本人可访问，备份代理服务仅转发不存储内容数据
4. 无第三方统计、无埋点、无广告；备份代理仅用于用户主动备份/恢复
5. 用户可自主部署、自主管理、自主删除全部数据
